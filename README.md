# Jikanwari（時間割PWA）

大学の時間割作成・シラバス検索・卒業要件確認をオフラインでも行えるPWA。旭川大学経済学部を想定した最小構成のVer.1〜Ver.11実装。

## 主な機能

- **時間割**: 曜日・時限ごとの時間割。セルをタップすると、割当済み科目の詳細（教員・単位・評価方法・シラバス）や、その時間帯に開講している他の科目の候補一覧（履修登録ウィザード）が表示され、ワンタップで追加・削除できる。
- **シラバス検索**: 科目名・教員名・概要・キーワードから部分一致・あいまい検索。ローカル（IndexedDB）にキャッシュ済みの科目はそこから即座に返し、未キャッシュの検索語のみ `/api/syllabus/search` がサーバー側でスクレイピングを試みる（失敗時はデモデータにフォールバック）。
- **卒業判定**: 入学年度別（経済学部経済学科 2024・2025・2026年度入学）の卒業要件に対応。必修・選択必修（専門/教養）・選択・自由選択の各区分の取得単位・不足単位・総取得単位を集計し、卒業可否とアドバイスを表示。
- **PWA**: `manifest.json` + Service Worker（`public/sw.js`）でホーム画面追加・オフライン閲覧に対応。
- **ローカル保存**: IndexedDB (`src/lib/db.ts`) に `courses` / `timetable` / `graduation`（履修済み科目） / `favorites` / `settings` を保存。サーバーには送信しない。

## 開発

```bash
npm install
npm run dev
```

`npm run build` でVercelへそのまま `git push` デプロイ可能（環境変数不要）。

## 既知の制限・要調整事項

- **卒業要件データ**（`src/lib/graduation-requirements.ts`）は、開発環境から大学サイト（asahikawa-u.ac.jp）へのネットワークアクセスがブロックされていたため実データを取得できず、一般的な経済学部カリキュラムを参考にしたプレースホルダー値になっている。本番運用前に学生便覧と突き合わせて修正すること。
- **シラバススクレイパー**（`src/lib/scraper.ts` / `src/lib/scraper-config.ts`）は、同様の理由で実際のCampusWebシステム（cx.asahikawa-u.ac.jp）のHTML構造を確認できなかったため、一般的なCampusWeb系システムを想定した汎用実装になっている。大学サイトへ到達可能な環境で実際のフォーム/検索結果のセレクタを確認し、`scraper-config.ts` の値を実構造に合わせて調整すること。調整するまでは検索は自動的にデモデータへフォールバックする。
