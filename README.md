# Jikanwari（時間割PWA）

大学の時間割作成・シラバス検索・卒業要件確認をオフラインでも行えるPWA。旭川大学経済学部経営経済学科を想定した実装。

## 主な機能

- **時間割**: 学年（1〜4年）× 学期（前期/後期/集中）× 曜日・時限の時間割。セルをタップすると、割当済み科目の詳細（教員・単位・評価方法・シラバス・卒業要件区分）や、その時間帯に開講している他の科目の候補一覧（履修登録ウィザード）が表示され、ワンタップで追加・削除できる。「必修を自動配置」で、選択中の学年・学期の必修科目を空きコマへ一括配置できる。
- **履修プランナー**: LLM（AI）は使わず、卒業要件の不足区分・科目データ・時間割の空きコマからルールベースで履修候補を提案。区分（必修/選択必修A〜E/選択/自由選択）ごとに未履修候補を一覧表示し、ワンタップで時間割に追加できる。
- **シラバス検索**: 科目名・教員名・概要・到達目標・評価方法・教科書・キーワードから部分一致・あいまい検索（全角半角統一、カタカナ→ひらがな変換、部分列マッチによるフォールバック対応）。ローカル（IndexedDB）にキャッシュ済みの科目はそこから即座に返し、未キャッシュの検索語のみ `/api/syllabus/search` がサーバー側でスクレイピングを試みる（失敗時はデモデータにフォールバック）。
- **卒業判定**: 入学年度別（経済学部経営経済学科 2023〜2026年度入学）の卒業要件に対応。必修・選択必修A〜E・選択・自由選択の各区分の取得単位・不足単位・総取得単位を集計し、円グラフ（達成率）・卒業可否・アドバイス（不足区分の候補科目、評価方法の偏りなど）を表示。各科目がどの区分としてカウントされるかは科目名から自動判定（`classifyCourse()`）され、手動指定でも上書きできる。
- **履修状況管理**: 履修済み/履修中/履修予定の3状態管理。履修中の科目も卒業要件の進捗に反映される。
- **PWA**: `manifest.json` + Service Worker（`public/sw.js`）でホーム画面追加・オフライン閲覧に対応。
- **レスポンシブUI**: モバイルは下部タブバー、タブレット/PCは左サイドナビに切り替わる。
- **ローカル保存**: IndexedDB (`src/lib/db.ts`) に `courses` / `timetable` / `graduation`（履修状況） / `favorites` / `settings` を保存。サーバーには送信しない。
- **サーバー側共有キャッシュ**: シラバスのライブスクレイピングに初めて成功した検索語の結果は、Next.jsのData Cache (`unstable_cache`) により外部DB・環境変数なしでサーバー側に30日間共有キャッシュされる。以降は同じ検索語について他の利用者がアクセスしても大学サイトへ再アクセスしない。

## 開発

```bash
npm install
npm run dev
```

`npm run build` でVercelへそのまま `git push` デプロイ可能（環境変数不要）。

## 既知の制限・要調整事項

- **卒業要件データ**（`src/lib/graduation-requirements.ts`）の必修科目名・選択必修A〜Eの分類ルール・単位数は、ユーザー提供の参考実装（学生便覧を参照して作成されたと見られるプロトタイプ）を元にしているが、開発環境から大学サイト（asahikawa-u.ac.jp）へのネットワークアクセスがブロックされていたため一次情報での最終確認はできていない。本番運用前に学生便覧と突き合わせて修正すること。
- **シラバスの実データ**: `src/lib/demo-courses.ts` は上記制約により実際にスクレイピングしたデータではなく、構造検証用のデモデータになっている。実際の科目データ（`data/asahikawa_courses.json` 相当）が用意でき次第、`upsertCourses()` で読み込む形に差し替えられる設計にしてある。
- **シラバススクレイパー**（`src/lib/scraper.ts` / `src/lib/scraper-config.ts`）は、同様の理由で実際のCampusWebシステム（cx.asahikawa-u.ac.jp/campusweb/slbssrch.do）のHTML構造を確認できなかったため、Apache Struts系の教務システムでよく見られる一般的な構造（GETでCSRFトークン等のhidden fieldを収集→POSTで検索）を想定した汎用実装になっている。大学サイトへ到達可能な環境で実際のフォーム/検索結果のセレクタを確認し、`scraper-config.ts` の値を実構造に合わせて調整すること。調整するまでは検索は自動的にデモデータへフォールバックする。
